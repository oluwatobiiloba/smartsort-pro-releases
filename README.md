# SmartSort Pro releases

Downloads and the update feed for SmartSort Pro, the copy of SmartSort sold from [smartsort-1pd.pages.dev/pro](https://smartsort-1pd.pages.dev/pro).

- Each release holds the notarized DMG (also as `SmartSort-Pro.dmg`, for the website's Download button) and `appcast.xml`, the feed SmartSort Pro checks for updates. The feed is signed with Sparkle's EdDSA key, so the app accepts only updates its developer made.
- This repository holds release files only. SmartSort's source code isn't here.

Free SmartSort is on the [Mac App Store](https://apps.apple.com/app/smartsort/id6777811126?mt=12).
